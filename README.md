📊 Estudo Power BI — SENAI Marília

Repositório criado para documentar meus estudos e práticas com Power BI durante as aulas no SENAI de Marília.

🧠 Objetivo

Explorar conceitos de análise de dados e visualização de informações, aplicando na prática o uso do Power BI para criar dashboards interativos e painéis dinâmicos.

⚙️ Conteúdo

Criação de dashboards interativos

Utilização de gráficos, indicadores e filtros dinâmicos

Transformação de dados brutos em insights visuais

Aplicação de boas práticas em visualização de dados

🧩 Ferramentas Utilizadas

Power BI Desktop

Excel / CSV (para bases de dados de exemplo)

🚀 Resultados

O projeto resultou em painéis visuais intuitivos, que demonstram como o Power BI pode auxiliar na tomada de decisões baseada em dados.
